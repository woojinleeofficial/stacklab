# 오프너 라이브러리 범위 (STEP 4에서 구축)

## 현 메타(TL-S2) 적합성 점검

TL-S2 규칙에서 오프너 가치에 영향을 주는 요소:

- **B2B 차징·Surge:** 어려운 클리어를 끊지 않고 4회 이상 이어야 Surge가 쌓인다 → 오프너 직후 B2B로 이어지는 후속 전개의 가치가 S1 시절보다 크다.
- **오프너 페이즈(첫 14블록 상쇄 2배):** 상대의 초반 공격이 쉽게 상쇄되므로, 첫 14블록 안에서 끝나는 큰 공격(DT Cannon 등)의 즉효성은 줄고 "14블록 이후에도 B2B를 이어갈 수 있는 모양"이 중요하다.
- **PC 공격량:** 클리어 공격 + 5줄(사용자 확인). 10줄 시절보다 낮지만 Quad/TSD PC면 9줄로 여전히 크다.
- **All-Mini+:** 비T 스핀도 B2B를 잇는다 → 자유 스태킹 전환 템플릿의 B2B 유지 수단이 늘었다.

## 초기 수록 범위

| openerId | 종류 | 수록 분기 | 비고 |
|----------|------|-----------|------|
| `tki` | 암기형 | TKI 기본형 + 미러, 첫 Bag의 T 위치별 분기(Hold 사용), TSD 후 TST/TSD 연결 2종 | 주력 후보 |
| `dt-cannon` | 암기형 | 2Bag 기본형 + 미러, TSD→TST 마무리, 실패 시 전환 분기 1종 | 2Bag 의존 → 가시정보 판정 차이가 큼 |
| `pco` | 암기형 | 첫 Bag 6블록 셋업 + 미러, 2번째 Bag PC 분기(가능 순서 전부 솔버로 검증), 2nd PC 연결 | PC = 클리어 공격 + 5줄(사용자 확인) |
| `pc-first` | 템플릿 | 빈 보드 1st PC(4줄)를 노리는 범용 전개: 솔버로 검증된 셋업 중 첫 Bag 순서에 맞는 것을 고름, 이후 2nd PC 연결 | 사용자 선호로 추가(D-019) |
| `free-transition` | 템플릿 | "평탄 6-3 또는 7-2 지형 + 구멍 0 + 높이 ≤ 6" 도달을 목표로 하는 전환 규칙 | 예외 전용 |

각 오프너의 정식 도식(블록 배치)은 STEP 4에서 공개 오프너 자료와 대조해 확정하고, 모든 분기를 엔진 재실행으로 증명한 뒤 `data/openers/<id>.toml`에 넣는다. 커버리지(`coverageEstimate`)는 첫 Bag 5,040가지 전수(1Bag 오프너) 또는 2Bag 표본 + 신뢰구간(2Bag 오프너)으로 계산한다.

## STEP 0 기술 검증에서 확인한 것

- 모양 기반 정의 + 채우기 탐색 + AND-OR 가시정보 판정이 동작함(`crates/opener`, 보고서 `docs/reports/step0_opener_spike.txt`).
- 손으로 그린 TSD 셋업이 7종 중 T를 뺀 6블록으로 타일링 불가능한 경우가 실제로 있었다 → 오프너 데이터는 **반드시 탐색으로 타일링·도달성을 증명**한 것만 수록한다는 원칙을 확정.
