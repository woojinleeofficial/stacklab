# 화면 와이어프레임 (UI-01 ~ UI-09)

기준 해상도 1280×720(창 크기 자유, 필드는 세로 기준 확대). egui 즉시 모드. 모든 문자열은 `app/i18n/ko.toml`.
대결·문제 화면은 입력을 막는 팝업·전환 애니메이션 없음(2장).

## UI-02 최초 설정·진단
단계 표시 `① 키 설정 → ② 오프너 선택 → ③ TL 기록(선택) → ④ 진단`
```
② 주력 오프너 [TKI ▾]  예외 [자유 스태킹 전환 ▾]   (주력=예외 선택 시 '다음' 비활성)
③ TETRA LEAGUE Glicko [____] ± RD [___]   [건너뛰기]
④ 진단 A B C D E F G H  각 2문제 · 임시 MMR 표시          [진단 건너뛰기]
```

## UI-07 오프너 관리
```
주력 TKI (숙련 1650 ±70)   예외 자유 스태킹 전환 (1520 ±120*)
적용 조건: 가능 → 주력 / 불가 확정 → 예외 / 둘 다 아님 → 자유 스태킹
분기별 숙련도 표 · 과거 기록(당시 역할 표시) · [이전 조합 복원] · [수동 재분석]
```

## UI-08 오프너 추천
```
           현재 조합            추천 조합
조합      TKI + 자유전환        PCO + TKI
적합도    71 (80%: 66~76)      83 (80%: 78~88)
근거      ...                  ... (모델 추정값 표시)
[추천 적용] [현재 유지] [나중에 결정]
 → '추천 적용' 시 변경 전후 비교 + "기존 숙련도는 그대로 보존됩니다" → [변경 확정]
```

## UI-09 통계·설정
탭: `기술별 기록 | 40라인 | 독립 측정 | TL 기록 입력(이력 표) | 입력(DAS/ARR/SDF/DCD, 키 중복 검사) | 백업/복원 | 성능 오버레이(FPS·프레임 시간·입력 지연, 로그 저장)`
