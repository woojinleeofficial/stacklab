# StackLab 사용 설명서

StackLab은 인터넷 없이 혼자 쓰는 테트로미노 스태킹 훈련 프로그램입니다. 짧은 문제로 기술을 연습하고,
AI와 대결해 실전 실력을 확인하며, 실력이 쌓이면 오프너(개막 전술) 조합을 한 번 추천받습니다.
규칙은 TETR.IO TETRA LEAGUE 시즌 2를 따른 **TL-S2** 룰셋입니다.

---

## 1. 설치와 제거

| 항목 | 내용 |
|---|---|
| 지원 OS | Windows 10/11 64비트 |
| 권장 사양 | 4코어 CPU, 8GB RAM, 내장 그래픽 이상 |
| 설치 | `StackLab-Setup-<버전>.exe` 실행 → 다음 → 설치. 관리자 권한이 필요 없습니다. |
| 설치 위치 | `%LOCALAPPDATA%\Programs\StackLab` |
| 기록 저장 위치 | `%APPDATA%\StackLab` (`stacklab.db`, `backups\`, `perf\`) |
| 제거 | Windows 설정 → 앱 → StackLab → 제거. **기록은 지워지지 않습니다.** 완전히 지우려면 `%APPDATA%\StackLab` 폴더를 직접 삭제하세요. |

설치 프로그램 없이 `stacklab.exe` 하나만 복사해 실행해도 동작합니다.

---

## 2. 처음 시작하기

대시보드 위쪽의 안내 상자를 순서대로 따라가면 됩니다.

1. **키 설정** — `설정` 화면에서 키와 조작감을 맞춥니다(아래 5장).
2. **오프너 선택** — `오프너` 화면에서 **주력**과 **예외** 오프너를 고릅니다. 둘은 서로 달라야 합니다.
   잘 모르겠다면 기본값(주력 TKI, 예외 자유 스태킹 전환)으로 시작해도 됩니다.
3. **TL 기록 입력(선택)** — TETR.IO 프로필의 TETRA LEAGUE **Glicko ± RD**가 있으면 대시보드의
   `실전 MMR` 칸에 입력하세요. AI 상대 선택이 처음부터 정확해집니다. 없으면 건너뛰세요.
4. **진단** — `훈련 시작`을 누르면 기술마다 한 문제씩 풀어 시작 실력을 잡습니다.
   바로 훈련하고 싶으면 `진단 건너뛰기`를 누르세요(실력은 훈련하며 빠르게 맞춰집니다).

---

## 3. 훈련 흐름

```
진단 → 12문제 → 미니 대결 → 12문제 → 미니 대결 → 12문제 → BO3 평가전 → 결과 → 다음 세트
```

- **사이클** = 12문제. 세 사이클과 대결 세 번이 한 **세트**입니다. 한 사이클은 15~20분 정도 걸립니다.
- 문제는 실력에 맞춰 **성공 확률이 약 75%**가 되도록 자동으로 골라집니다. 약한 기술이 조금 더 자주 나옵니다.
- 같은 문제를 다시 풀어도 문제 수는 한 번만 셉니다. 중간에 프로그램을 꺼도 **보고 있던 문제부터** 이어집니다
  (끝내지 않은 문제는 세지 않습니다).

### 3.1 문제 화면

- 왼쪽에 **목표**와 **남은 시간**, 가운데에 필드(그림자 블록 표시), 오른쪽에 NEXT가 있습니다.
- 용어 위에 마우스를 올리면 짧은 설명이 나옵니다.
- **힌트(H)**, **다시 시작(R)**, 결과 화면의 **되감기·정답 보기**는 마음껏 써도 됩니다.
  다만 쓴 시도는 연습으로만 인정되고 **기술 MMR에는 반영되지 않습니다.**

### 3.2 기술 영역

| 영역 | 연습 내용 |
|---|---|
| A 피네스·속도 | 최소 입력으로 정확한 위치에 놓기 (피네스 성공은 배치 성공과 따로 기록) |
| B 스태킹·Hold | 구멍·높이 조건을 지키며 쌓기 |
| C 스핀 | T-Spin, All-Mini+ 스핀 만들기 |
| D 퍼펙트 클리어 | 필드를 완전히 비우기 (PC 공격 = 지운 줄 공격 + 5줄) |
| E 오프너 | 고른 주력·예외 오프너 쌓기와 분기 판단 |
| F 공격 | Quad, 콤보, B2B·Surge 활용 |
| G 방어·복구 | 가비지 지형 정리, 상쇄, 버티기 |
| H 순간 판단 | 여러 정답이 있는 배치 선택 (신뢰도가 낮은 문제는 '비평가'로 표시) |

## 4. AI 대결

- **미니 대결**: 사이클 사이에 한 판씩. 건너뛰거나 나중으로 미룰 수 있으며, 실전 MMR에는 반영되지 않습니다.
- **BO3 평가전**: 세 번째 사이클 뒤. 먼저 2승하면 끝나고(최대 3판, 무승부·시간 제한 없음) **실전 MMR**이 바뀝니다.
  미루거나 평가 없이 세트를 끝낼 수도 있습니다(실전 MMR 유지).
- 상대는 예상 승률 40~60%인 AI가 자동으로 골라집니다. AI는 사람처럼 실제 키를 누르고, 보이는 정보(NEXT 5개, Hold)만 씁니다.
- 경기 중 프로그램이 꺼지거나 오류가 나면 그 판은 **무효**가 되어 다시 진행합니다. 패배로 기록되지 않습니다.
- 평가전 결과 화면에서 엔진이 관측한 약점이 표시되고, 다음 사이클 출제 비중에 반영됩니다.

## 5. 설정

`설정` 화면에서 바꾸며, 바로 저장됩니다.

| 항목 | 단위·범위 (TETR.IO와 같음) | 기본값 |
|---|---|---|
| DAS | 1–20 F (0.1 단위) | 10 F |
| ARR | 0–5 F | 2 F |
| DCD | 0–20 F | 1 F |
| SDF | 5–40X, 41 = ∞ | 6X |

F는 프레임(1/60초)입니다.

| 동작 | 기본 키 | 동작 | 기본 키 |
|---|---|---|---|
| 왼쪽 / 오른쪽 | ← / → | 홀드 | C |
| 소프트 드롭 | ↓ | 180° 회전 | A |
| 하드 드롭 | Space | 다시 시작 | R |
| 시계 방향 회전 | ↑, X | 힌트 | H |
| 반시계 방향 회전 | Z | 일시정지 | Esc |

- 키 버튼을 누른 뒤 원하는 키를 누르면 바뀝니다. 한 동작에 키를 2개까지 둘 수 있습니다.
- 한 키를 두 동작에 쓰려고 하면 막고 어떤 동작과 겹치는지 알려 줍니다.
- `성능 측정 오버레이`를 켜면 오른쪽 아래에 FPS·프레임 시간·시뮬레이션/AI 시간·입력 처리 지연이 표시되고,
  `%APPDATA%\StackLab\perf\perf-<시각>.csv`에 1초마다 기록됩니다.

## 6. 오프너와 추천

- `오프너` 화면에서 주력·예외를 바꾸고, 각 오프너의 분기 그림·조건·**실행 가능 범위**를 봅니다.
  "100% 가능" 같은 표시는 항상 어떤 범위(예: 첫 가방 7! 전부를 확인)에서 확인했는지와 함께 나옵니다.
- 주력 오프너 조건이 안 맞으면 예외 오프너로, 그것도 안 되면 자유 스태킹으로 넘어갑니다.
- **오프너 추천은 자동으로 딱 한 번** 나옵니다: 오프너 문제 10회 이상 + 평가전 관측 4판 이상을 처음 채운
  정상 평가전 뒤입니다. 추천은 근거(적합도와 80% 구간)를 보여 주며, 적용하려면 **2단계 확인**이 필요합니다.
  바꿔도 각 오프너의 숙련도 기록은 그대로 남습니다. 이후에는 `오프너` 화면에서 직접 추천을 다시 받아 볼 수 있습니다.

## 7. 통계·기록

`통계` 화면의 탭:

- **기술별 기록**: 기술 MMR, 문제 수, 성공률, 유효 시도, 피네스 성공률
- **경기 기록**: 미니 대결·평가전 결과와 실전 MMR 변화 (모든 판의 리플레이가 저장됩니다)
- **40라인**: 40줄을 지우는 시간 측정 모드(사이클과 무관). 3초 카운트다운 후 시작, 완료 시간·PPS·입력 수를 기록합니다.
- **독립 실력 측정**: 3세트마다 대시보드에서 제안되며 언제든 실행할 수 있습니다. 기술마다 2문제(D 1500,
  같은 제한시간)의 처음 보는 문제 16개로, 사이클·MMR과 상관없이 지난 측정과 비교합니다.
  힌트·되감기·정답 보기를 쓴 문제는 실패로 셉니다. 중간에 나가면 그 측정은 버려집니다.
- **TL 기록**: TETRA LEAGUE 기록 입력과 입력 이력(입력 당시 앱 MMR, 보정값)
- **백업·복원**: 아래 8장

## 8. 백업과 복원

- `지금 백업`을 누르면 모든 기록이 `%APPDATA%\StackLab\backups\stacklab-<시각>.json` 하나로 저장됩니다.
- 목록에서 `복원` → `복원 확정`을 누르면 현재 데이터가 그 시점으로 **통째로** 바뀝니다.
  복원이 실패하면 아무것도 바뀌지 않습니다.
- 다른 PC로 옮길 때는 백업 파일을 새 PC의 같은 폴더에 넣고 복원하세요.

## 9. 문제 해결

| 증상 | 해결 |
|---|---|
| 창이 열리지 않거나 화면이 깨짐 | 그래픽 드라이버를 업데이트하세요. 그래도 안 되면 환경 변수 `STACKLAB_RENDERER=glow`를 설정해 OpenGL로 실행합니다. |
| 한글이 네모로 보임 | Windows 기본 글꼴 '맑은 고딕'(`malgun.ttf`)이 있어야 합니다. |
| 기록을 다른 곳에 두고 싶음 | 환경 변수 `STACKLAB_DATA_DIR`에 폴더를 지정하세요. |
| 설치가 정상인지 확인 | 명령 프롬프트에서 `stacklab.exe --self-check` → 데이터 폴더의 `self-check.txt`에 결과가 기록됩니다. |
| 키가 반응하지 않음 | `설정`에서 해당 동작에 키가 있는지, 일시정지(Esc) 상태가 아닌지 확인하세요. |

StackLab은 TETR.IO와 관련이 없는 개인 훈련 도구입니다. 사용한 오픈소스 목록은
설치 폴더의 `docs\THIRD_PARTY_LICENSES.txt`에 있습니다.
