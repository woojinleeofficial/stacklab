# 난이도 앵커 세트 (명세 6.2)

각 영역의 앵커 세트는 D = 1500으로 고정되는 기준 문제 **10개**다. 앵커는 (생성기 버전, 시드, 파라미터)로 정의하고 생성 결과 fingerprint를 함께 저장한다(D-014). 실제 시드·fingerprint는 해당 영역 생성기가 생기는 단계(STEP 2·3·4)에서 `data/anchors/<영역>.toml`로 확정한다. 아래는 앵커의 **파라미터 정의**다.

기준 사용자상: "TETRA LEAGUE 중간권(약 Glicko 1500)이 75% 확률로 푸는 문제"가 아니라, 앱 척도의 원점이다. 실제 TL 눈금과의 대응은 6.3 앵커(TL 기록)로 맞춘다.

| 영역 | 앵커 파라미터 (D=1500) | 초기 변환 함수에서 D를 올리는 요인 |
|------|------------------------|-----------------------------------|
| A 피네스 | 빈 보드, 무작위 목표 위치·회전, 최소 입력 2~3, 제한 15초 | 최소 입력 수, 180° 필요, 시간 단축 |
| B 스태킹 | 높이 4~6 지형, 8블록, Next 5, 목표 "구멍 0·높이 8 이하" | 블록 수, 시야 축소, 시작 높이, 울퉁불퉁함 |
| C 스핀 | 준비된 TSD 슬롯 + 2~3블록 준비 후 TSD | 준비 블록 수, 회전 진입 난도(TST/킥), 비T 스핀, 분기 |
| D PC | 2줄 PC, 남은 블록 3~4, Hold 1회 이하 | 줄 수(2→4), 블록 수, 정답 경로 수(적을수록 ↑), 시간 |
| E 오프너 | 주력 오프너 첫 Bag, 유리한 순서(커버 다수 경로) | 불리 순서, 분기 수, 전환 판단 포함, 시간 |
| F 공격 | B2B ×1 유지하며 Quad 1회, 10블록 | 목표 공격량, B2B 유지 길이, Surge 타이밍 |
| G 방어 | 가비지 4줄(구멍 정렬 2), 대기 공격 없음, 10블록 생존·2줄 이상 지우기 | 가비지 깊이, 구멍 분산, 대기 공격량, Clutch 필요 |
| H 판단 | 2지선다 배치, 정답 경로 차이 명확(평가 차 큼), 10초 | 선택지 수, 평가 차 축소, 제한시간 단축 |

초기 변환 함수: `D = 1500 + Σ wᵢ·(파라미터ᵢ − 앵커값ᵢ)` (영역별 wᵢ는 STEP 3 시뮬레이션 사용자로 1차 보정). 사이클 종료마다 파라미터 구간 레이팅을 Glicko-2로 갱신(구간 RD 하한 60, policy.toml).
